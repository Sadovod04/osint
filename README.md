# parcer — найти свой цифровой след, чтобы его удалить

`footprint.py` — OSINT self-check. По e-mail / username / телефону / имени находит
твои аккаунты и упоминания в **открытых** источниках, строит **чек-лист удаления**
(аккаунт → куда идти удалять) и пишет единый отчёт в `.txt`
(перезаписывается при каждом запуске).

> ⚠️ Для проверки **своих** данных или разведки в рамках **авторизованного**
> пентеста. Не для сбора данных о посторонних.

---

## Установка (Ubuntu)

```bash
sudo apt install python3-phonenumbers pipx
pipx install maigret holehe
pipx ensurepath          # добавит ~/.local/bin в PATH, нужен новый терминал
```

Всё работает и на голой стандартной библиотеке — тогда username-скан идёт по
встроенному списку `sites.json` (~20 сайтов), телефон разбирается грубо.

---

## Запуск

```bash
# минимум — только dork-запросы + разбор телефона, без сети
python3 footprint.py --name "Иван Иванов" --phone "+7 999 123-45-67"

# обычный прогон
python3 footprint.py --email me@example.com --username mynick --online

# МАКСИМУМ: весь список maigret, 8 вариантов ника + перестановки,
#          свой домен, утечки, видимость ВК
python3 footprint.py \
  --email me@example.com --username mynick \
  --phone "89990001122" --name "Иван Иванов" \
  --online --full --permute --max-variants 8 --ext-timeout 7200 \
  --site mydomain.ru --hibp-key "$HIBP_KEY" --vk-token "$VK_TOKEN" \
  --out report.txt
```

### Флаги

| Флаг | Назначение |
|------|-----------|
| `--email / --username / --phone / --name` | входные данные (нужен хотя бы один) |
| `--online` | разрешить сетевые запросы (**без него — только dorks + телефон**) |
| `--full` | maigret по всем ~3300 сайтам вместо топ-509 |
| `--permute` | maigret перебирает перестановки/склейки ников |
| `--variants a,b,c` | доп. ники вручную |
| `--max-variants N` | сколько авто-вариантов генерить из имени/почты (по умолч. 6) |
| `--site DOMAIN` | разведка своего домена: crt.sh, DNS, открытые файлы, Wayback |
| `--hibp-key KEY` | утечки + пасты по почте ([haveibeenpwned.com/API/Key](https://haveibeenpwned.com/API/Key)) |
| `--vk-token TOKEN` | публичная видимость **своего** ВК (поля, группы, друзья) |
| `--proxy URL` | прокси для maigret (Tor обычно только мешает — 95% ошибок) |
| `--out FILE` | файл отчёта (перезаписывается) |
| `--timeout / --ext-timeout` | таймаут одного HTTP / всего maigret+holehe |
| `--json` | дополнительно вывести структуру в stdout |

## Что в отчёте

1. **`[ЧЕК-ЛИСТ УДАЛЕНИЯ]`** — все найденные аккаунты (maigret + holehe +
   встроенный скан), сгруппированы по сервису, с ссылкой «куда идти удалять»
   из `deletion_links.json` (нет в базе → поисковый запрос).
2. `[ТЕЛЕФОН]` — страна / оператор / тип линии (нужен `phonenumbers`).
3. `[GRAVATAR]` — публичный аватар/профиль по хэшу почты.
4. `[УТЕЧКИ — HaveIBeenPwned]` — список брешей + пасты (нужен `--hibp-key`).
5. `[HOLEHE]` — на каких сервисах зарегистрирована почта.
6. `[MAIGRET]` — сырой вывод по всем вариантам ника.
7. `[VK]` — видимость своего профиля (при `--vk-token`).
8. `[WAYBACK]` — архивные копии найденных профилей и сайта: **остаются после
   удаления**, + ссылка на запрос удаления из архива.
9. `[DOMAIN]` — поддомены, DNS, открытые файлы (при `--site`).
10. `[ПОИСКОВЫЕ ЗАПРОСЫ]` — dork'и под Google / Bing / DuckDuckGo / Yandex.
11. `[КАК УДАЛЯТЬ — ОБЩЕЕ]` + `[БРОКЕРЫ ДАННЫХ — opt-out]`.

Метки: `[+]` найдено, `[ ]` нет, `[?]` сайт не ответил. **Проверяй ссылки
глазами** — среди `[+]` бывают ложные совпадения (особенно на общих никах).

## Границы

- «Всю сеть» и «все сообщения человека» спарсить нельзя — нет такого API,
  чаты не индексируются, соцсети блокируют ботов.
- Утечки: только HIBP (легально, показывает **факт** попадания). Сервисы,
  отдающие сами записи из дампов, не подключены — они возвращают данные любого
  человека, и «удалить себя» из них нельзя.
- Телефон — без «пробива» владельца.
